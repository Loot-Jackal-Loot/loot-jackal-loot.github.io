# loot-jackal-loot.github.io

Homepage of **LOOT JACKAL LOOT!**, published with GitHub Pages at <https://loot-jackal-loot.github.io/>.

It presents the game, the trailer and the credits, with links to Google Play and to the LITE demo on itch.io.

## Files

- `index.html`: the homepage.
- `assets/site.css`: shared style (fonts, colors, background, panels, footer). Every page on the domain can use it with `<link rel="stylesheet" href="/assets/site.css">`.
- `assets/web/`: compressed images and icons used by the page; the originals are in `assets/`.
- `assets/fonts/`: Space Mono (SIL Open Font License, see `OFL.txt`) and M41 Lovebit.
- `app-ads.txt`: authorized ad sellers file for AdMob.
